DirtShack — Hero Images
=======================

Each top-level page loads its hero banner from this folder by filename.
To change a page's hero, just replace the matching .jpg (keep the same name):

  home.jpg       -> Homepage hero
  shop.jpg       -> Shop / product archive
  product.jpg    -> Single product view pages
  cart.jpg       -> Cart page
  myaccount.jpg  -> My Account page
  braap.jpg      -> Braap (blog) page

Notes
-----
- Use wide, landscape JPGs (recommended ~1920x1080 or wider). They are shown
  full-bleed and cropped to ~48vh tall, focused around the vertical centre.
- If a file here is missing, the page falls back to the original homepage
  image so it never renders broken.
- The images currently in this folder are placeholders (copies of the two
  original site images) — replace any of them with the final artwork.
